# Проверка на реальном iPhone

Этот список — план ручной проверки; он не утверждает, что проверки уже выполнены.

- [ ] Кабель с данными, заблокированный экран, подтверждение «Доверять».
- [ ] Чтение большой медиатеки, повторное подключение, два USB-устройства.
- [ ] Импорт одного HEIC/JPEG и одного длинного MOV/MP4; открыть результат.
- [ ] Live Photo и RAW: проверить обе части и сопутствующие файлы.
- [ ] Копия в папку по месяцам и прямо в выбранную папку, внешний диск.
- [ ] Повторный импорт пропускает существующие копии.
- [ ] После удаления локальной копии файл импортируется заново.
- [ ] Одинаковые имена с разных устройств/папок не перезаписывают данные.
- [ ] Обрыв кабеля в середине копирования, затем повторный импорт.
- [ ] «Остановить после файла» завершает текущий файл и прекращает очередь.
- [ ] Недостаточно места, недоступная папка, повреждённая история.
- [ ] Закрытие окна и Cmd+Q во время операции не прерывают перенос.
- [ ] На нескольких ненужных файлах: окно удаления показывает точный список; отмена и неподтверждённая кнопка не удаляют ничего.
- [ ] Подтверждённое удаление: проверить список на iPhone, размер свободного места и отчёт.
- [ ] Обрыв USB во время удаления: проверить частичный результат и повторный список после подключения.
- [ ] Смена устройства/списка во время подтверждения не применяет старое решение.
- [ ] iCloud Photos и ограничения iOS: корректная недоступность удаления/ошибки.
- [ ] Первый запуск скачанного ZIP на отдельном Apple Silicon и Intel Mac.
