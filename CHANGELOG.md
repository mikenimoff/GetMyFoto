# История изменений

## 1.0.1 — 2026-11-26

Сборка 2.

- Исправлено удержание старого объекта iPhone после перезапуска USB-драйвера: новое соединение определяется по постоянному идентификатору или USB-порту.
- «Обновить» перечитывает каталог работающего соединения; для неготового соединения поиск запускается заново с ожиданием остановки прежнего поиска.
- Список заполняется во время чтения медиатеки; готовность каталога проверяется также по состоянию системного API.
- Добавлен обход дерева папок, если плоский список файлов ещё отсутствует.
- Ошибки подключения и ограничения доступа больше не отображаются как бесконечная загрузка.
- Повторный запуск другой копии приложения переводит пользователя к уже открытому окну.
- Добавлены проверки сопоставления устройства при смене объекта драйвера.

## 1.0.0 — 2026-11-26

Первая версия, сборка 1.

- Подключение iPhone по USB через ImageCaptureCore.
- Список фото, видео и сопутствующих файлов; выбор, поиск и фильтры.
- Копирование в папку на Mac или внешнем диске, группировка по месяцам.
- Учёт собственных переносов, пропуск сохранённых файлов и защита от перезаписи.
- Удаление с iPhone с проверкой списка и явным подтверждением.
- Выбор сохранённых файлов для очистки, отчёт об операции.
- Иконка, версия в интерфейсе и Info.plist.
- Universal binary для Apple Silicon и Intel, macOS 13+.
- Автоматическая сборка и публикация релизов по тегам GitHub.

Перенос и удаление требуют проверки с реальным iPhone. Сборка не нотариализована Apple.
